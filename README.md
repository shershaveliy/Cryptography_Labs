# Лабораторная работа №1

Меню:

| Пункт | Действие |
|---|---|
| 1 | Контрольные примеры и проверки режимов/набивок |
| 2 | Демонстрация DES и DEAL на массивах и пяти типах файлов |
| 3 | Шифрование или расшифрование своего файла с вводом параметров |

Из терминала в папке проекта:

```text

dotnet run
dotnet run -- test
dotnet run -- demo
```
